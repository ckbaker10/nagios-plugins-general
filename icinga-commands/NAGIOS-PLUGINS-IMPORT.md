# Nagios Plugins - Icinga2 CheckCommands

Generated by `nagios-plugins-parser/parse_nagios_plugins.py` from the
nagios-plugins `release-2.5` sources and the `--help` output of the
plugins built by `build/build.sh`. The commands use the stable path
`/opt/monitoring-nagios-git` (symlink to the installed version, see
`docs/VERSIONING.md`), so a version change on the hosts needs no change here.

| File | Command names | Plugin path |
|---|---|---|
| `commands-nagios-plugins.conf` | `git_check_*` | `/opt/monitoring-nagios-git/libexec` (static) |
| `commands-nagios-plugins.conf.dynamic-path` | `check_*` | `PluginDir` |

Both files contain 66 CheckCommands with 930 arguments (722 with
description), exactly the plugins contained in the build. Both were validated
with `icinga2 daemon -C`; the rendered command lines were checked with a
recording dummy plugin in a running Icinga2.

## Regenerate

```bash
git clone --branch release-2.5 --depth 1 \
    https://github.com/nagios-plugins/nagios-plugins.git work/nagios-plugins
nagios-plugins-parser/capture-help.sh work/help      # needs dist/ (build/build.sh)

nagios-plugins-parser/parse_nagios_plugins.py -p work/nagios-plugins --help-dir work/help \
    --command-prefix git --plugin-path /opt/monitoring-nagios-git/libexec \
    -o icinga-commands/commands-nagios-plugins.conf
nagios-plugins-parser/parse_nagios_plugins.py -p work/nagios-plugins --help-dir work/help \
    -o icinga-commands/commands-nagios-plugins.conf.dynamic-path
```

Without `--help-dir` descriptions come from `print_help()` in the C sources
(fewer, none for Perl/shell plugins) and commands are also generated for
plugins that are not part of the build.

## How the parser works

| Source | Parsed from |
|---|---|
| C | every `struct option NAME[]` table (including `STD_LONG_OPTS`, options returning constants like `SNI_OPTION`) plus the `getopt()`/`getopt_long()` option string for short-only options |
| Perl | `GetOptions()`; forms of one variable are grouped, only forms accepting the argument are used |
| Shell | `case` labels assigning `$2` |
| Descriptions | `--help` output of the built plugins, fallback `print_help()` with `UT_*` macros |
| Manual | `nagios-plugins-parser/manual_definitions.py` |

Manual definitions (2.4.12, 2.5):

- `check_dummy`, `check_oracle`: positional arguments (`check_dummy_state`,
  `check_dummy_text`; `check_oracle_mode` such as `--tns`, then `sid`, `user`,
  `password`, `tablespace`, `critical`, `warning`)
- `check_sensors`: only `--ignore-fault`
- `check_icmp`: getopt only; readable variable names (`check_icmp_warning`,
  `check_icmp_packets`, ...). `-O` is declared with an argument upstream but
  ignores it, so it is passed as `-O 1` when `check_icmp_out_of_order` is true
- `check_http`: `-H/--hostname` is the virtual host (`check_http_vhost`);
  `--IP-address` gets `$address$` by default
- `check_disk`: thresholds and units are ordered before `--partition`,
  because they only apply to paths given after them
- `check_file_age`: only `-f` takes the file name (`check_file_age_file`)

## Variables and argument types

Variables follow `$<plugin>_<long option>$` with `-` replaced by `_`, e.g.
`$check_disk_warning$`, `$check_http_ssl$`. The host option (`--hostname`,
`-H`, ...) defaults to `$address$`.

| Option type | Icinga2 argument | Variable value |
|---|---|---|
| with argument | `value` | string/number; an array repeats the option (`--header A --header B`) |
| flag | `set_if` | boolean |
| optional argument (`check_http --ssl`, `check_apt --upgrade`, ...) | value lambda | `true` → `--ssl`, `"1.2+"` → `--ssl=1.2+` |

## Installation

```bash
scp commands-nagios-plugins.conf icinga-master:/etc/icinga2/zones.d/global-templates/
icinga2 daemon -C && systemctl reload icinga2
```

Then import via Icinga Director → Kickstart Wizard → Run Import.

The `.dynamic-path` variant needs `PluginDir` set to
`/opt/monitoring-nagios-git/libexec` in `constants.conf`.

Migrating from the earlier `commands-nagios-plugins-2.4.12.conf`: command and
variable names are unchanged (except `check_ssh_remote_protocol`), only the
path moves to `/opt/monitoring-nagios-git/libexec`. Replace the file on the
master and run the Director import once.
